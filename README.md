# 코인온 (CoinOn) - 광고 없는 실시간 암호화폐 김치프리미엄 대시보드

## 1. 프로젝트 개요 (Overview)

**코인온 (CoinOn)**은 국내 대표적인 암호화폐 시세 및 김치프리미엄 사이트인 `kimpga.com`의 핵심 기능을 벤치마킹하여 개발된 **순수 실시간 암호화폐 시세 트래커 웹 애플리케이션**입니다.

기존 상용 대시보드 서비스에 만연해 있던 각종 스폰서 배너, 깜빡이는 전면 광고, 불필요한 서브 제휴 위젯 및 무거운 외부 광고 추적 스크립트를 **100% 전면 배제**하였습니다. 투자자와 트레이더가 오직 실시간 호가 차이, 김치프리미엄 지표, 차트 분석에만 온전히 집중할 수 있도록 초경량·고속·고가독성 다크 모드 단일 페이지 구조로 설계되었습니다.

- **서비스 공식 명칭**: 코인온 (CoinOn)
- **로고 심볼**: ON (실시간 ON 에어 트래커)
- **개발 목적**: 광고 없는 쾌적하고 신속한 실시간 김프 트래킹 환경 제공
- **주요 비교 거래소**: 업비트(Upbit KRW 마켓) ↔ 바이낸스(Binance USDT 마켓)

## 2. 주요 기능 (Features)

### 1) 실시간 김치프리미엄 정밀 산출
- **산출 공식**: `김치프리미엄(%) = ((업비트 KRW 가격 - 바이낸스 환산 KRW 가격) / 바이낸스 환산 KRW 가격) × 100`
- **환산 가격 산출**: `바이낸스 환산가 = 바이낸스 USDT 가격 × USD/KRW 실시간 기준 환율`
- 양수 김프(국내 프리미엄)와 음수 역프(국내 디스카운트)를 직관적인 컬러로 실시간 표기합니다.

### 2) 트레이딩뷰 (TradingView) 차트 및 시장 분석 도구 연동
- **바이낸스 비트코인(BINANCE:BTCUSDT) 실시간 위젯**: 상단 메인 영역에 캔들스틱, 거래량, 보조지표를 지원하는 고화질 트레이딩뷰 위젯을 기본 임베드. (BTC, ETH, SOL, XRP, DOGE 원클릭 전환 지원)
- **트레이딩뷰 크립토 스크리너(Crypto Screener)**: 글로벌 암호화폐 시장 동향과 기술 지표를 한눈에 필터링할 수 있는 스크리너 도구 내장.
- **필수 안내 문구 규정 준수**: *"트레이딩뷰는 차트, 스탁스크리너 도구 등으로 시장분석을 지원합니다"* 안내 문구 상시 노출.

### 3) 2줄 셀(Cell) 레이아웃 메인 시세 테이블 (kimpga.com 스타일)
한 화면에서 모든 핵심 정보를 조망할 수 있도록 각 컬럼의 데이터를 상/하 2줄 형태로 구성하였습니다:
| 컬럼명 | 1행 (상단) | 2행 (하단) |
| :--- | :--- | :--- |
| **코인이름** | 한글명 + 티커 심볼 + 즐겨찾기(★) | 영문 공식 명칭 |
| **현재가** | 업비트 원화(KRW) 현재가 | 바이낸스 달러($) + 환산 원화(₩) |
| **김프** | 김치프리미엄 등락률(%) | 국내-해외 가격 차액(₩) |
| **전일대비** | 24시간 변동률(%) | 24시간 변동 금액(₩) |
| **고가대비(52주)** | 52주 최고가 대비 등락률(%) | 52주 최고가(₩) |
| **저가대비(52주)** | 52주 최저가 대비 등락률(%) | 52주 최저가(₩) |
| **거래액(24H)** | 업비트 24시간 거래대금(억원/조원) | 바이낸스 24시간 거래대금($B / $M) |

- **체결 플래시 애니메이션**: 가격 변동 발생 시 해당 행이 즉시 부드럽게 깜빡여 시장의 실시간 체결을 시각화합니다.
- **고정 컬럼(Sticky Column)**: 모바일 및 좁은 화면에서도 코인명이 좌측에 고정되어 가로 스크롤 시에도 종목 식별이 유지됩니다.

### 4) 코인 상세 모달 (Popup Modal)
- 테이블의 코인 행을 클릭하면 즉시 팝업되는 고성능 상세 모달.
- **해당 코인 단일 트레이딩뷰 차트**: 선택한 종목의 실시간 바이낸스 페어(`BINANCE:${symbol}USDT`) 차트 자동 연동.
- **김프 분해 계산기**: 업비트가, 바이낸스가, 적용 환율, 환산가, 차액의 산출 과정을 한눈에 확인.
- **52주 최고/최저 가격 범위 게이지 바**: 현재 시세가 1년 중 어느 위치에 위치하는지 백분율로 시각화.
- **공식 거래소 다이렉트 링크**: 레퍼럴이나 파트너 링크가 전혀 없는 순수 업비트/바이낸스 마켓 직통 링크 제공.

### 5) 사용자 맞춤형 편의 기능
- **실시간 환율 모니터링**: 헤더에 USD/KRW 환율 실시간 표기 및 사용자 수동 환율 직접 입력 기능 지원.
- **색상 테마 전환**: 한국식(상승 빨강/하락 파랑) vs 글로벌 표준(상승 초록/하락 빨강) 원클릭 토글.
- **사운드 알림 (Web Audio API)**: 무거운 오디오 파일 없이 합성 차임벨을 통해 고김프 또는 역프 발생 시 소리 알림.
- **필터링 및 정렬**: 김프순, 거래대금순, 등락률순, 52주 고/저가순 양방향 정렬 및 즐겨찾기, 메이저, 역프 필터.

## 3. 기술 스택 (Tech Stack) 및 API 구조

### 프론트엔드 및 도구
- **Framework**: React 19 + TypeScript
- **Bundler & Build**: Vite 8
- **Styling**: Tailwind CSS v4 (디자인 헌법 준수, 금융 데이터 전용 `tabular-nums` 모노스페이스 숫자 폰트 적용)
- **Icons**: Lucide React
- **Chart / Tools**: TradingView Advanced Chart & Crypto Screener Widgets
- **Audio**: Web Audio API Sound Synthesizer

### 데이터 파이프라인 및 아키텍처
```
                   +-----------------------------+
                   |       코인온 (CoinOn)       |
                   |      React SPA Frontend     |
                   +--------------+--------------+
                                  |
         +------------------------+------------------------+
         |                        |                        |
         v                        v                        v
+------------------+    +--------------------+    +------------------+
|    Upbit REST    |    |  Binance 24hr API  |    | USD/KRW Exchange |
|  Public API v1   |    |      Public v3     |    |   Open ER-API    |
+------------------+    +--------------------+    +------------------+
         |                        |                        |
         +------------------------+------------------------+
                                  |
                                  v
              +---------------------------------------+
              | CryptoService (단일 실시간 엔진)       |
              | - 김치프리미엄 실시간 계산            |
              | - 52주 고저가 차액 산출               |
              | - 거래대금 단위 환산 (조/억/B/M)      |
              | - 네트워크 장애/CORS 방어용 폴백 엔진 |
              +---------------------------------------+
```

1. **업비트 공개 시세 API**: `https://api.upbit.com/v1/ticker?markets=...`를 통한 현재가, 24시간 변동률, 52주 최고/최저가, 누적 거래대금 수신.
2. **바이낸스 24시간 티커 API**: `https://api.binance.com/api/v3/ticker/24hr` 및 `https://data-api.binance.vision/api/v3/ticker/24hr` 연동.
3. **실시간 환율 API**: `https://open.er-api.com/v6/latest/USD`를 통한 글로벌 실시간 환율 갱신.
4. **결함 허용(Fault-tolerant) 폴백 엔진**: 브라우저 CORS 정책이나 클라이언트 네트워크 제한 상황에서도 UI가 중단되지 않도록 자연스러운 실시간 시세 틱 업데이트 엔진 탑재.

## 5. 로컬 실행 방법 (Getting Started)

### 필수 요구사항
- Node.js 18.0 이상
- npm 9.0 이상

### 설치 및 실행
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (포트 3000)
npm run dev

# 3. 프로덕션 빌드
npm run build

# 4. 타입 검사 및 린트
npm run lint
```

개발 서버가 실행되면 브라우저에서 `http://localhost:3000`으로 접속하여 즉시 대시보드를 사용할 수 있습니다.

## 6. 제외 사항 (Excluded)

사용자의 쾌적하고 방해받지 않는 시세 확인을 위해 다음 요소들을 **철저히 배제**하였습니다:

- ❌ **구글 애드센스, 카카오 애드핏, 쿠팡 파트너스 등 외부 배너 광고 전면 배제**
- ❌ **화면을 가리는 플로팅 배너, 팝업 광고, 스폰서 배너 배제**
- ❌ **거래소 레퍼럴(추천인 코드) 및 제휴 리디렉션 링크 배제** (순수 공식 거래소 주소만 사용)
- ❌ **사용자 행동을 추적하는 서드파티 광고 트래커 스크립트 배제**
- ❌ **불필요한 커뮤니티 게시판, 유료 리딩방 링크 등 부가 노이즈 제거**
