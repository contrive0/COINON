# 코인온 (CoinOn) - 광고 없는 실시간 암호화폐 김치프리미엄 대시보드

## 1. 프로젝트 개요 (Overview)

**코인온 (CoinOn)**은 국내 대표적인 암호화폐 시세 및 김치프리미엄 사이트인 `kimpga.com`의 장점을 벤치마킹하여 개발된 **순수 실시간 암호화폐 시세 및 프리미엄 트래커 웹 애플리케이션**입니다.

기존 상용 대시보드 서비스에 만연해 있던 각종 스폰서 배너, 깜빡이는 전면 광고, 불필요한 제휴 위젯 및 무거운 외부 광고 추적 스크립트를 **100% 전면 배제**하였습니다. 투자자와 트레이더가 오직 실시간 호가 차이, 김치프리미엄 지표, 차트 분석에만 온전히 집중할 수 있도록 초경량·초고속·고가독성 다크 모드 단일 페이지 구조로 설계되었습니다.

- **서비스 공식 명칭**: 코인온 (CoinOn)
- **로고 심볼**: ON (실시간 ON 에어 트래커)
- **개발 목적**: 광고 없는 쾌적하고 신속한 실시간 김프 트래킹 및 모바일 반응형 차트 환경 제공
- **주요 비교 거래소**: 업비트(Upbit KRW 마켓) ↔ 바이낸스(Binance USDT 마켓)

## 2. 최신 업데이트 및 모바일 특화 기능 (Recent Updates)

사용자 요청 화면(레퍼런스 이미지)과 동일하게 모바일 및 반응형 뷰를 전면 개편하였습니다:

### 1) 상단 매크로 지표 4선 (Top Macro Indicator Cards)
화면 최상단에 글로벌 주요 자산 지표 4개를 나란히 배치하여 거시 경제와 시장 흐름을 한눈에 조망할 수 있습니다:
1. **코스피 (KOSPI)**: 네이버 증권 오픈 API 기반 실시간 지수 및 전일대비 등락률
2. **비트코인 (BTC)**: 업비트 실시간 원화 현재가 및 24시간 변동률
3. **국제 금 (Gold)**: 바이낸스 실물 금 연동 토큰(PAXG/USDT) 기반 온스당 실시간 달러 가격
4. **WTI 원유 (Crude Oil)**: 글로벌 원유 기준 지표 실시간 추적

### 2) 중앙 트레이딩뷰 차트 & 봉 단위 로컬스토리지 기억 (TradingView Chart & Timeframe Memory)
- **차트 상단 인터벌 툴바**: `1시`, `4시`, `날`, `주`, `달`, `15분` 단위의 빠른 봉 주기 선택 버튼 배치 (**기본값: `날` (일봉)**)
  - `1시`: 60분봉 (TradingView interval: `'60'`)
  - `4시`: 240분봉 (TradingView interval: `'240'`)
  - `날`: 일봉 (TradingView interval: `'D'`)
  - `주`: 주봉 (TradingView interval: `'W'`)
  - `달`: 월봉 (TradingView interval: `'M'`)
  - `15분`: 15분봉 (TradingView interval: `'15'`)
- **로컬 스토리지 자동 저장 (`localStorage`)**: 사용자가 클릭하여 선택한 봉 단위를 브라우저 로컬 저장소(`coinon_chart_interval`)에 즉시 기록하며, **재접속하거나 새로고침을 하더라도 마지막에 선택했던 봉 단위가 자동으로 복원**됩니다.
- **종목 전환 및 접기/펼치기**: `BTC 바이낸스`, `ETH 바이낸스`, `SOL 바이낸스`, `XRP 바이낸스`, `DOGE 바이낸스` 원클릭 변경 및 차트 접기/펼치기 지원.
- **필수 안내 문구 규정 준수**: *"트레이딩뷰는 차트, 스탁스크리너 도구 등으로 시장분석을 지원합니다"* 문구 상시 노출.

### 3) 하단 메인 테이블 필터 툴바 & 선택값 로컬스토리지 기억 (Table Filter Bar & Persistence)
레퍼런스 디자인에 맞춘 컴팩트 툴바를 제공하며, **사용자가 마지막으로 선택한 탭(전체, 즐겨찾기, 메이저, 김프, 역프, 거래대금)이 브라우저 로컬 저장소(`coinon_category_filter`)에 자동 저장되어 재접속이나 새로고침 시에도 그대로 유지**됩니다:
- **`전체`**: 전체 원화 마켓 코인 조회
- **`★ 즐`**: 즐겨찾기(별표 등록) 종목만 모아보기
- **`메이저`**: BTC, ETH, SOL, XRP 등 시총 상위 핵심 코인 필터
- **`김프`**: 김치프리미엄이 양수(+)인 종목만 필터
- **`역프`**: 김치프리미엄이 음수(-)인 역프리미엄 종목만 필터
- **`거래대금`**: 일 거래대금 1,000억원 이상 거래량 상위 종목 필터
- **`BTC, 암호화폐 검색`**: 한글명, 영문명, 티커 심볼 즉각 실시간 검색

### 4) 한 화면 5컬럼 최적화 및 종목명 가로폭 축소 (Single-Screen Mobile 5-Column View)
모바일 브라우저의 가로 폭(360px ~ 430px) 안에서 가로 스크롤 없이 **"이름, 현재가, 김프, 전일대비, 거래액(일)"** 5개 핵심 컬럼이 한눈에 들어오도록 최적화하였습니다:
- **이름 컬럼 가로폭 축소 (상하 2단 압축 구조)**:
  - **1행 (상단)**: 업비트 공식 코인 로고 아이콘(`https://static.upbit.com/logos/{symbol}.png`) + **한글명** (예: `🟠 비트코인`, `솔라나`)
  - **2행 (하단)**: 즐겨찾기 별(`★`) + **티커 심볼** (예: `BTC`, `SOL`) (미니 아이콘 제거로 가독성 및 공간 최적화)
  - 기존에 가로 공간을 과도하게 차지하던 영문명 및 가로형 나열 방식을 제거하고, 상하 2단으로 직관적 배치하여 이름 컬럼의 폭을 절반 이하로 압축.
- **현재가 컬럼**:
  - **1행**: 업비트 원화 현재가 (콤마 표기, 가로 여백 최적화)
  - **2행**: 해외(바이낸스) 실시간 환산 원화가
- **김프 컬럼**:
  - **1행**: 실시간 김치프리미엄 등락률(`+0.28%`)
  - **2행**: 국내-해외 김프 차액(`291,254`)
- **전일대비 컬럼**:
  - **1행**: 24시간 변동률(`-1.02%`)
  - **2행**: 24시간 변동 금액(`-1,071,000`)
- **거래액(일) 컬럼**:
  - **1행**: 업비트 24시간 거래대금(`650억`)
  - **2행**: 바이낸스 24시간 거래대금 원화 환산 표기(`1조 2,954억`)
- **무스크롤 고정 레이아웃 (`table-fixed`) 및 헤더 글자 단일행(`whitespace-nowrap`) 최적화**:
  - 모바일 화면에서 "전일대비", "거래액(일)" 글자가 좁은 폭으로 인해 두 줄로 줄바꿈되는 현상을 방지하기 위해 5개 컬럼의 가로 비율을 `[23%, 23%, 14%, 20%, 20%]`로 정밀 재조정하였습니다.
  - 여유가 충분한 김프 컬럼 폭을 줄이고(16% → 14%), 글자 수가 많은 전일대비(20%) 및 거래액(일)(20%)의 가로폭을 확장하고 좌우 패딩을 `px-0.5`로 컴팩트화하였습니다.
  - 헤더 텍스트 및 셀에 `whitespace-nowrap`을 적용하고 정렬 아이콘에 `shrink-0` 및 모바일 전용 미세 간격(`ml-0.5`)을 부여하여 초소형 스마트폰 화면에서도 글자가 두 줄로 꺾이지 않고 온전히 한 줄로 가독성 높게 표시됩니다.

### 5) 초기 화면 로딩 시 데이터 수신 전 '-' 플레이스홀더 표시 (Unloaded Data '-' Indicator)
사용자가 처음 화면을 열었을 때, 업비트나 바이낸스 서버로부터 실제 실시간 시세를 수신하기 전까지 잘못된 더미 숫자나 과거 데이터가 노출되지 않도록 엄격하게 처리하였습니다:
- **현재가**: 업비트 수신 전까지 1행(업비트 현재가)은 `-`, 바이낸스 수신 전까지 2행(해외 환산가)은 `-`로 표시
- **김프 (김치프리미엄)**: 국내(업비트)와 해외(바이낸스) 양쪽 데이터가 모두 수신되어 정확한 실시간 김프가 산출되기 전까지 1행(김프 %) 및 2행(차액)을 `-`로 표시
- **전일대비**: 업비트 24시간 변동률 수신 전까지 1행(등락률 %) 및 2행(변동금액)을 `-`로 표시
- **거래액(일)**: 업비트 및 바이낸스 각 거래소의 거래대금 수신 전까지 `-`로 표시
- **52주 고저가 (데스크톱)**: 업비트 통계 데이터 수신 전까지 `-`로 표시
- **데이터 도착 상태 플래그(`hasUpbitData`, `hasBinanceData`) 관리**:
  - 앱 초기 마운트 시 모든 코인의 데이터 수신 상태를 미수신(`false`)으로 설정.
  - 업비트 REST API 또는 실시간 웹소켓(`wss://api.upbit.com/websocket/v1`)으로부터 티커가 도착하는 즉시 `hasUpbitData: true`로 활성화되어 실시간 가격과 변동폭이 즉각 반영됩니다.
  - 바이낸스 REST API로부터 시세가 도착하는 즉시 `hasBinanceData: true`로 활성화되어 해외 환산가 및 김프가 계산됩니다.
  - 바이낸스 미상장 코인(업비트 단독 상장 종목)의 경우 해외 시세 및 김프가 불필요하게 0으로 오기표되지 않고 정상적으로 `-` 상태를 유지합니다.

## 3. 핵심 시스템 아키텍처 및 데이터 연동

### 1) 네이버 모바일 실시간 환율 API 연동
- **엔드포인트**: `https://m.search.naver.com/p/csearch/content/qapirender.nhn?key=calculator&pkid=141&q=%ED%99%98%EC%9C%A8&where=m&u1=keb&u6=standardUnit&u7=0&u3=USD&u4=KRW&u8=down&u2=1`
- 하나은행 기준 최신 USD/KRW 매매기준율을 주기적으로 fetch하여 소수점 1자리(예: `1,442.5원`) 정밀도로 유지합니다.
- 임의의 고정 환율을 사용하지 않고 오직 실시간 환율을 기준으로 모든 코인의 원화 환산 가격과 김치프리미엄을 재계산합니다.

### 2) 업비트 전체 원화(KRW) 마켓 299개 전 종목 동적 로드 & 실시간 웹소켓 연동
- **전체 원화 마켓 동적 수신 (`api.upbit.com/v1/market/all`)**: 앱 구동 시 업비트 공식 마켓 목록 API를 호출하여 `KRW-`로 시작하는 **모든 원화 마켓 코인 목록(299개 전체)**을 실시간 동적으로 가져옵니다.
- **고정 배열 한계 탈피 및 신규 상장 자동 감지**: 업비트에 신규 코인이 상장되더라도 재배포나 코드 수정 없이 실시간으로 테이블 목록에 자동 렌더링됩니다.
- **'전체' 선택 시 299개 전 종목 완벽 렌더링**: '전체' 필터 탭 선택 시 업비트 원화 마켓의 모든 코인(299개)이 누락 없이 표시되며, 기본 정렬인 현재가 내림차순(고가순)으로 정갈하게 나열됩니다.
- **업비트 실시간 웹소켓(WebSocket) 스트리밍**: `wss://api.upbit.com/websocket/v1`에 299개 전체 마켓 코드를 구독하여, 실시간 체결이 발생할 때마다 초당 수십 회의 가격 변동과 플래시 효과가 테이블에 실시간 반영됩니다.
- **결함 방지 병렬 데이터 파이프라인**: 299개 전체 코인 데이터셋(`initialCoins.ts`)이 완벽히 구성되어 있어 네트워크 지연 상황에서도 즉각 화면에 표출되며, 백그라운드에서 동적 병합(Merge)을 통해 시세 데이터가 끊기지 않도록 방어 설계되었습니다.

### 3) 불필요한 '평균김프' 위젯 제거
- 개별 코인 간 가중치가 반영되지 않아 투자 판단에 혼선을 주던 '평균김프' 표시를 제거하고, 깔끔한 헤더와 상단 매크로 지표로 공간 효율성을 극대화하였습니다.

## 4. PWA (Progressive Web App) 모바일 독립 앱 지원

코인온 웹사이트는 스마트폰에서 홈 화면에 추가 시 브라우저 상단 주소창(URL bar)과 하단 툴바가 사라지고 **네이티브 모바일 앱과 완전히 동일한 독립 창(`standalone`)**으로 구동되도록 PWA 표준 사양이 완벽하게 구현되었습니다:

### 1) 웹 앱 매니페스트 (`public/manifest.json`)
- **`display: "standalone"`**: 스마트폰 홈 화면에서 실행 시 브라우저 URL 주소창 및 컨트롤러가 숨겨져 독립된 네이티브 앱 환경 제공.
- **`start_url: "./"` 및 `scope: "./"`**: GitHub Pages 배포 경로(`https://contrive0.github.io/COINON/`) 및 로컬 개발 환경 모두에서 경로가 깨지지 않도록 상대 경로(`./`)를 정확히 준수.
- **앱 식별자 & 이름**:
  - `name`: "코인온 - 실시간 암호화폐 김치프리미엄"
  - `short_name`: "코인온"
  - `theme_color`: `#0f172a` (상단 시스템 상태바와 통일된 딥 네이비 슬레이트)
  - `background_color`: `#0b0e14` (앱 시작 스플래시 화면 다크 배경)
  - `orientation`: `portrait-primary` (모바일 세로 모드 최적화)
- **아이콘 자산 (Icons)**:
  - `./icon-192.png`: 192x192 표준 홈 화면 아이콘 (`purpose: any`)
  - `./icon-512.png`: 512x512 고해상도 스플래시 화면 아이콘 (`purpose: any`)
  - `./icon-maskable-512.png`: 안드로이드 원형/스쿼클 적응형 마스커블 아이콘 (`purpose: maskable`)
  - `./icon.svg`: 무손실 벡터 아이콘

### 2) 서비스 워커 (`public/service-worker.js`) & 캐싱 전략
- **앱 셸(App Shell) 사전 캐싱**: `index.html`, `manifest.json`, 앱 아이콘 등 핵심 정적 에셋을 캐싱하여 네트워크가 불안정하거나 오프라인인 환경에서도 앱 셸이 즉각 실행됩니다.
- **실시간 API & 웹소켓 우회 (Bypass Strategy)**:
  - 실시간 시세가 생명인 코인 대시보드 특성에 맞춰 **업비트 API(`api.upbit.com`), 바이낸스 API(`api.binance.com`), 네이버 환율 API, 웹소켓(`wss://`) 요청은 서비스 워커 캐시 대상에서 엄격히 제외**하여 언제나 100% 실시간 최신 시세를 네트워크에서 직접 수신합니다.
- **상대 경로 스코프 등록**: `index.html`에서 `navigator.serviceWorker.register('./service-worker.js', { scope: './' })`로 등록하여 서브디렉토리 배포 시에도 정상 작동합니다.

### 3) 인앱 설치 안내 버튼 (`PWAInstallButton`) 및 iOS 사파리 가이드
- **스마트 설치 감지 (`usePWAInstall`)**:
  - 이미 홈 화면에 설치되어 `standalone` 모드로 실행 중인 경우 설치 버튼을 자동으로 숨김 처리.
  - 안드로이드/크롬/엣지 환경: 브라우저 기본 설치 프롬프트(`beforeinstallprompt`)를 연동하여 원클릭 설치 지원.
  - iOS 사파리 환경: 애플의 정책상 자바스크립트 직접 설치 API가 지원되지 않으므로, "공유(Share) 버튼 → '홈 화면에 추가'" 과정을 3단계로 친절하게 안내하는 전용 모달 창 팝업 제공.
